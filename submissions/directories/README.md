# MCP directory submissions

`mcp-directories.json` is the canonical listing copy and status record for external MCP directories. It separates confirmed publication from prepared or automatically discovered listings so public documentation never overstates availability.

The Official MCP Registry is the primary machine-readable publication. Glama already indexes the repository, and PulseMCP can discover Registry-published servers automatically. The free mcp.so submission copy is ready for its public GitHub intake thread. Smithery requires either a public HTTPS MCP endpoint or a pre-built MCPB artifact before submission.
