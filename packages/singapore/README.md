# @olano/mcp-singapore

The aggregate server exposes every tool from the data.gov.sg, OneMap, LTA DataMall, and Singapore
weather packages, plus cross-agency research tools.

```bash
npx @olano/mcp-singapore
```

For HTTP:

```bash
npx @olano/mcp-singapore --transport http --host 127.0.0.1 --port 3000
```
