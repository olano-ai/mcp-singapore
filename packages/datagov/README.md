# @olano/mcp-datagov

Read-only MCP tools for documented data.gov.sg dataset and real-time APIs.

```bash
npx @olano/mcp-datagov
```

`DATA_GOV_SG_API_KEY` is optional for testing and recommended for higher production limits. The
server uses the key only in the `x-api-key` header sent to data.gov.sg.
