# `@olano/mcp-core`

Shared, typed runtime utilities for the [Olano Singapore MCP suite](https://github.com/olano-ai/mcp-singapore), including bounded HTTP responses, application-level error validation, retry handling, rate limiting, and an optional private disk cache.

Most users should install the aggregate server instead:

```bash
npx -y @olano/mcp-singapore
```

See the [monorepo README](https://github.com/olano-ai/mcp-singapore#readme) for setup, security, data-source, and package documentation.
